# 💼 RecruitEase - Job Portal Web Application

## 🚀 About Project
**RecruitEase** ek modern Job Portal Web Application hai jisme recruiters aur job seekers dono interact kar sakte hain.

- Job seekers jobs search aur apply kar sakte hain  
- Recruiters job post kar sakte hain  
- Simple aur user-friendly UI  

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- React.js

### Backend
- Java
- Spring Boot
- Hibernate

### Database
- MySQL

---

## ✨ Features

✅ User Registration & Login  
✅ Role-Based Access (Admin, HR, Student)  
✅ Job Posting (HR/Admin)  
✅ Job Search & Apply (Student)  
✅ Dashboard System  
✅ REST API Integration

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
